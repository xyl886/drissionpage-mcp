# 01 · 定位与元素

## 定位语法全表

DrissionPage 的定位串有自己的解析规则，**不是 CSS**。规则优先级从高到低：

| 写法 | 含义 | 示例 |
|---|---|---|
| `'文本内容'` | 按元素文本匹配（含子孙文本） | `page.ele('登录')` |
| `'@属性=值'` | 属性**精确等于** | `page.ele('@id=kw')` |
| `'@属性:值'` | 属性**包含**（模糊） | `page.ele('@class:read-content')` |
| `'@属性'` | 属性存在 | `page.ele('@disabled')` |
| `'@属性=值@@属性2=值2'` | 多条件与 | `page.ele('@id=su@@type=submit')` |
| `'tag:div'` / `'t:div'` | 标签名 | `page.ele('t:iframe')` |
| `'css:...'` | 真 CSS 选择器 | `page.ele('css:#list .item')` |
| `'xpath:...'` / `'x://...'` | XPath | `page.ele('xpath://h3[contains(., "章")]')` |
| `'.cls'` | ⚠️ 等价 `@class=cls`，**class 属性必须整串全等** | 见下方大坑 |
| `'.cls1 cls2'` | ✅ 完整 class 串（空格按原序连接）可精确命中 | `page.ele('.a b c')` |
| `'#id'` | 等价 `@id=id` | |
| `'t:tag@属性=值'` | 标签 + 属性组合 | `page.ele('t:div@id=article')` |

## 头号大坑：`.cls` 是「class 属性整串全等」，不是 CSS 类名

DrissionPage 在 `DrissionPage/_functions/locator.py` 的 `_preprocess()` 中把
`'.cls'` 改写为 `@class=cls`、`'#id'` 改写为 `@id=id`。
`@class=` 是**精确等于**，所以 `'.xxx'` 里的内容必须与元素 class 属性值**完全一致**。

```html
<div class="read-content j_readContent">
```

实测（`tests/../probe_api_behavior.py` 可直接复现）：

| 写法 | 结果 | 原因 |
|---|---|---|
| `.read-content` | ✘ | 属性值 `"read-content j_readContent"` ≠ `"read-content"` |
| `.read-content j_readContent` | ✔ | 与 class 属性整串相等 |
| `@class:read-content` | ✔ | 冒号是**包含匹配** |
| `css:.read-content` | ✔ | 真 CSS 类选择器 |

```python
page.ele('.read-content')                    # ✘ 少写了一个 class 就不匹配
page.ele('.read-content j_readContent')      # ✔ 把 class 属性整串抄下来
page.ele('@class:read-content')              # ✔ 包含匹配
page.ele('css:.read-content')                # ✔ 真 CSS
```

**实践结论**：`.cls` 不是不能用，而是**必须写完整**。
真实项目里常见的写法就是把 class 属性原样抄进定位串：

```python
# 对应 class="leading-xl mb-md font-sans text-xl font-bold"
page.ele('.leading-xl mb-md font-sans text-xl font-bold')
```

三种写法怎么选：

| 写法 | 优点 | 缺点 |
|---|---|---|
| `.完整 class 串` | 与站点 HTML 一一对应，最直观 | class 顺序/数量一变就失效 |
| `@class:其中一个` | 抗 class 增删 | 可能命中多元素 |
| `css:.其中一个` | 标准 CSS 语义，可组合 `>`、`:nth-child` 等 | 与 DP 其它写法语法不同 |

`wait.eles_loaded()` 与 `ele()` 用同一套解析逻辑，同样受影响。

## 元素信息读取

```python
ele.tag                 # 标签名
ele.text                # 显示文本（含子孙）
ele.raw_text            # 原始文本
ele.texts()             # 文本节点列表；text_node_only=True 只取直接文本
ele.html                # outerHTML
ele.inner_html          # innerHTML
ele.attr('href')        # 属性值（注意：href 被绝对化，见下）
ele.attrs               # 全部属性 dict
ele.property('value')   # JS property（运行时值，非 HTML 属性）
ele.link                # <a> 的绝对化 URL（推荐用它取链接）
ele.value               # 表单元素值
ele.css_path / ele.xpath  # 元素的 CSS 路径 / XPath
ele.rect.location / .size / .midpoint / .viewport_midpoint
ele.states.is_displayed / .is_enabled / .is_selected / .is_checked / .is_clickable
```

**`attr('href')` 的坑**：DrissionPage 会基于当前页面把 href 绝对化，
HTML 里写 `/chapter/1.html` 会返回 `https://站点/chapter/1.html`。
再手动拼域名就得到 `https://a.comhttps://a.com/...` 这种坏链接。
**取链接一律用 `ele.link`**；确需 `attr('href')` 时先判断是否已以 `http` 开头。

## 相对关系查找

```python
ele.parent(level_or_loc=1)         # 父元素（可传层级数字或定位串）
ele.child(locator, index=1)        # 子元素
ele.next( ) / ele.prev( )          # 后面 / 前面的同级元素
ele.before( ) / ele.after( )       # 文档顺序的前 / 后兄弟
ele.nexts() / ele.prevs() / ele.afters() / ele.befores()
ele.north() / ele.south() / ele.east() / ele.west()   # 方位元素
```

多级定位推荐位置无关的 XPath：

```python
page.ele('xpath://h3[contains(., "第一章")]/following::ul[1]//a')
```

## 多元素与静态解析

```python
eles = page.eles('css:#list .item')      # 返回元素列表
ele.s_ele('@class=name')                 # 用静态解析（lxml）在元素内查，快但不含 JS 渲染结果
ele.s_eles('tag:a')
```

`page.s_ele()` / `page.s_eles()` 同理。静态解析速度远快于元素定位，
**但只反映当前 HTML 快照**，动态渲染出来的内容取不到。

## iframe 与 Shadow DOM

```python
# iframe：三种写法，成功率依次递增
frame = page.get_frame('t:iframe')       # 最规范
frame = page.ele('t:iframe')             # 最简洁
frame = page.eles('t:iframe')[0]         # 成功率最高

# Shadow DOM

```

### 动作链（Actions）

单次 click/input 表达不了的操作，用动作链按序执行：

```python
# 滑块验证码
page.actions.move_to(滑块).hold().move(offset_x=位移, offset_y=4, duration=2.5).release()

# 组合键：Ctrl+A 全选
page.actions.key_down('ctrl').type('a').key_up('ctrl')

# 画布 / 地图：按坐标移动再滚轮缩放
page.actions.move_to((x, y)).scroll(delta_y=-300)
```

可用方法：`move_to` / `move` / `click` / `r_click` / `m_click` / `hold` / `release` /
`r_hold` / `r_release` / `type` / `input` / `key_down` / `key_up` /
`scroll` / `down` / `up` / `left` / `right` / `wait`。

**注意**：`key_down` 之后必须配 `key_up`，`hold` 之后必须配 `release`，
否则键/鼠标一直处于按下状态，后续所有操作都会异常。
异常分支里要补上释放动作。

### 修改元素（ele.set.*）

```python
ele.set.attr('data-id', '999')       # 改属性
ele.set.property('value', '新值')     # 改 JS 属性
ele.set.innerHTML('<b>新内容</b>')    # 改 innerHTML
ele.set.style('display', 'block')    # 改内联样式（把隐藏元素显示出来）
ele.set.value('新值')                 # 改表单值
```

实测：`ChromiumElementSetter` **只有这 5 个方法** ——
`attr` / `property` / `innerHTML` / `style` / `value`。
注意是 `innerHTML`（驼峰），没有 `inner_html`，也没有 `html`。

改的是当前页面 DOM，**刷新即失效**，只适合临时绕开前端限制
（例如把 `display:none` 的元素显示出来再截图）。

## JS 中的 `this` 约定

```python
ele.run_js('return this.innerText')            # this 指代该元素
ele.run_js('return arguments[0]', '参数')       # arguments 取传入参数
page.run_js('return document.title', as_expr=True)   # as_expr 直接求值
```

## 页面内主动取回数据的套路

不便直接读取时，注入 JS 把数据挂到全局，再用 `run_js` 取回：

```python
page.run_js('''
  window.__data = [];
  const ob = new MutationObserver(ms => ms.forEach(m => window.__data.push(m.target.textContent)));
  ob.observe(document.body, {childList: true, subtree: true});
''')
# 之后
data = page.run_js('return window.__data')
```
