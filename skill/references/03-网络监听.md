# 03 · 网络监听（抓包）

## 铁律：先开监听，再触发请求

监听**不回溯**。必须在触发动作（导航、点击、翻页）之前 `listen.start()`，
否则拿不到已经发出的包。

```python
page.listen.start('api/search')     # 1) 先开
page.ele('@id=search').click()      # 2) 再触发
packet = page.listen.wait(timeout=10)   # 3) 再取
page.listen.stop()                  # 4) 收尾
```

## API 全表

```python
page.listen.start(targets=None, is_regex=None, method=None, res_type=None)
#   targets   URL 关键字；字符串或列表
#   is_regex  targets 是否按正则解析
#   method    只监听指定方法，如 ('GET', 'POST')
#   res_type  是否按资源类型过滤（默认 True）

page.listen.wait(count=1, timeout=None, fit_count=True, raise_err=None)
#   返回一个或多个 packet；超时行为受 raise_err 控制（默认跟全局设置走）

page.listen.steps(count=None, timeout=None, gap=1)
#   生成器，逐个产出 packet，适合流式接口

page.listen.set_targets(targets=True, is_regex=False, method=('GET','POST'), res_type=True)
page.listen.wait_silent(timeout=10)   # 等网络静默：一段时间内无新请求
page.listen.pause(clear=True)   # 暂停（可选清空已抓）
page.listen.resume()
page.listen.clear()             # 清空已抓的包
page.listen.stop()
page.listen.targets             # 当前监听目标
```

**注意超时行为**：`wait()` 在超时且 `raise_err` 未显式关闭时会抛异常。
批量采集里务必用 try/except 包住，把「没抓到」当成正常分支处理，否则
一个接口没响应就会中断整个任务。

## 等「网络静默」，不要猜 sleep

异步拼装、瀑布流、视频页面的加载时机根本猜不准。`wait_silent()` 等的是
「一段时间内没有新请求」，比任何固定 sleep 都可靠：

```python
page.listen.start(True, method=True, res_type=True)   # True = 监听全部
page.get(url)
page.listen.wait_silent(timeout=15)     # 等页面把异步请求发完
html = page.html                        # 此时拿到的 HTML 才是完整的
```

实测结论：

- `start()` 与 `start(True)` 等价 —— 都是「监听全部」，`listen.targets` 属性为 `True`；
- `start('api')` 得到 `targets={'api'}`（集合），说明字符串会被收进集合做包含匹配；
- `wait_silent` 在已经静默时**立即返回 True**（不白等），页面持续请求时才等到超时。

## packet 对象结构

```python
packet.url                    # 请求 URL
packet.method                 # 请求方法
packet.resourceType           # 资源类型（XHR / Document / Script ...）
packet.frameId                # 所属 frame
packet.request.url / .method / .headers / .postData     # 请求侧
packet.response.status / .headers / .body / .raw_body   # 响应侧
```

取值示例：

```python
packet = page.listen.wait(timeout=10)
if packet:
    print(packet.url, packet.method)
    print(packet.request.postData)          # POST 请求体
    print(packet.response.status)           # 状态码
    body = packet.response.body             # 已解析（JSON 会自动转 dict）
    raw = packet.response.raw_body          # 原始字节
```

## 实战套路

### 1. 先分析接口，再决定是否脱离浏览器

先用监听摸清接口的 URL、请求头、请求体、签名参数，再评估能否直接
用 `SessionPage` / requests 复现。签名逻辑复杂时保留浏览器方案。

```python
page.listen.start('api/list')
page.ele('@class:next-page').click()
for packet in page.listen.steps(count=5, timeout=15):
    print(packet.url, packet.request.postData)
```

### 2. 边滚动边抓（瀑布流 / 无限加载）

```python
page.listen.start('api/feed')
seen = set()
for _ in range(20):
    page.scroll.to_bottom()
    page.wait(1.5, 2.5)              # 等接口回来
    packet = page.listen.wait(count=1, timeout=3)
    if packet and packet.url not in seen:
        seen.add(packet.url)
        items.extend(packet.response.body.get('data', []))
```

### 3. 大响应体只取需要的字段

`response.body` 对 JSON 会自动解析；若响应很大，只提取需要的键，
不要把整个 body 打印或落盘。

### 4. 从网络包里捞媒体地址（视频 / 音频 / 图片）

视频站点的真实媒体地址往往不在 DOM 里，而是在异步请求或 CDN 响应中。
按 `resourceType` 筛，再看 URL 后缀：

```python
MEDIA_TYPES = {'Media', 'XHR', 'Fetch'}
MEDIA_SUFFIX = ('.m3u8', '.mp4', '.mpd', '.ts', '.m4s', '.jpg', '.png')

page.listen.start(True, method=True, res_type=True)   # 监听全部
page.get(page_url)
page.listen.wait_silent(timeout=15)                   # 等请求发完

candidates = set()
for packet in page.listen.steps(timeout=0.5):         # steps 是生成器
    url = packet.url or ''
    rtype = getattr(packet, 'resourceType', '')
    if rtype in MEDIA_TYPES or url.split('?')[0].endswith(MEDIA_SUFFIX):
        candidates.add(url)
page.listen.stop()
```

要点：

- `resourceType` 是浏览器给的分类（`Media` / `XHR` / `Fetch` / `Document` / `Script` …），
  比按 URL 猜更可靠；
- `.m3u8` 只是**播放列表**，拿到后还要下载 `.ts` 分片并合并；
- 带签名的 CDN 地址有时效，抓完尽快下载；
- `steps(timeout=...)` 是**生成器**，用 `for` 迭代；遍历完记得 `stop()`。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| `wait()` 抛超时异常 | 正常现象：没抓到包。用 try/except 转成空结果；确认 `start()` 在触发动作之前 |
| 抓不到 XHR | targets 关键字与实际 URL 不符；先用 `listen.start()` 不带 targets 抓全部，看清 URL 再收窄 |
| 抓到重复包 | 页面重试或轮询导致；用 URL + postData 做去重 |
| 拿不到响应体 | 部分资源类型没有 body；确认 `resourceType` 是 `XHR`/`Fetch`/`Document` |
| 页面一直在加载 | 长轮询 / WebSocket / 视频导致；用 `page.stop_loading()` 强制停下 |
| WebSocket 数据拿不到 | `listen` 面向 HTTP；WebSocket 帧需用 CDP `Network.webSocketFrameReceived` 事件自行接收 |

## 与 CDP 的分工

`listen` 覆盖绝大多数接口抓包；需要更底层能力时直接用 CDP：

```python
page.run_cdp('Network.enable')
page.run_cdp('Page.getNavigationHistory')
page.run_cdp_loaded('Runtime.enable')      # 等待文档加载后再执行
```
