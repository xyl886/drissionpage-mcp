# 04 · 下载与上传

## 下载

### 方式一：设置下载目录 + 普通点击

```python
page.set.download_path(r'D:\downloads')      # 设置下载目录
page.set.download_file_name('报告.xlsx')      # 预设文件名（可选）
page.ele('@class:export-btn').click()
page.wait.download_begin(timeout=30)          # 等下载开始
```

### 方式二：点击并等待完成（推荐，能拿到结果）

```python
mission = page.ele('@class:export-btn').click.to_download(
    save_path=r'D:\downloads',    # 保存目录
    rename='报告.xlsx',            # 重命名
    timeout=60,                    # 超时秒数
    by_js=False,                   # 是否用 JS 点击
)

mission.wait(show=False)          # 阻塞直到下载完成
print(mission.path)               # 最终文件路径
print(mission.rate)               # 进度
print(mission.is_done)            # 是否完成
```

`to_download` 返回的是下载任务对象（DownloadMission），可以查询进度、取消：

```python
mission = page.ele('@id=dl').click.to_download(save_path=r'D:\downloads')
mission.wait(show=False)
if not mission.is_done:
    mission.cancel()
```

### 下载目录相关设置（版本差异）

| 设置 | 4.0.5.6 | 4.1.x |
|---|---|---|
| `set.download_path(path)` | ✔ | ✔ |
| `set.download_file_name(name)` | ✔ | ✔ |
| `set.when_download_file_exists('rename'/'overwrite'/'skip')` | ✔ | ✔ |

两版都挂在 `tab.set`（TabSetter）上，用法一致。

### 常见问题

| 现象 | 处理 |
|---|---|
| 文件下到默认目录 | 没设 `set.download_path`，或页面用了 blob/新窗口下载 |
| 点击后没反应 | 目标不是直接触发下载的元素，可能需要先悬停展开菜单 |
| 下载一直不完成 | 大文件正常；检查 `timeout` 是否足够；用 `mission.rate` 看进度 |
| blob: 下载拿不到文件 | 浏览器内存下载，需改用 CDP `Page.setDownloadBehavior` 或抓原始 URL 用 requests 下 |
| 文件名乱码 | 服务端 Content-Disposition 编码问题，用 `rename` 指定 |

## 上传

### 方式一：预设文件 + 点击触发（适合复杂上传控件）

```python
page.set.upload_files([r'D:\a.png', r'D:\b.png'])   # 预设待上传文件
page.ele('@class:upload-btn').click()               # 点击上传按钮
page.wait.upload_paths_inputted()                   # 等路径写入输入框
```

多个文件用列表传入；传字符串时用换行分隔多个路径。

### 方式二：直接对 file input 点击并上传（一步完成）

```python
page.ele('css:input[type=file]').click.to_upload(
    [r'D:\a.png'],
    by_js=False,
)
```

### 处理系统文件选择框

DrissionPage 通过 CDP 的 `Page.fileChooserOpened` 拦截文件选择框，
**不需要**操作系统级自动化（不弹真实对话框）。所以：

- 不要用 pyautogui 之类的工具去点系统对话框；
- 只要文件 input 被触发，`set.upload_files` 预设的路径就会自动填入；
- 若页面上传控件是自定义 div（非 input[type=file]），点它同样会触发
  `fileChooserOpened`，预设依然生效。

### 上传失败的排查顺序

1. 确认文件路径存在且是**绝对路径**；
2. 确认 `set.upload_files()` 在**点击之前**调用；
3. 若是拖拽上传控件，改用 `page.actions` 拖拽或 `Input.dispatchDragEvent`；
4. 上传后页面通常有异步校验，用 `wait.eles_loaded('@class:upload-success')` 确认。

## 下载 + 上传组合场景

```python
# 下载模板 → 填写 → 再上传
page.set.download_path(r'D:\work')
mission = page.ele('@class:download-template').click.to_download(save_path=r'D:\work')
mission.wait(show=False)

target = mission.path
# ... 用 openpyxl 等修改 target ...

page.set.upload_files(target)
page.ele('@class:upload').click()
page.wait.upload_paths_inputted()
page.ele('@class:submit').click()
```
